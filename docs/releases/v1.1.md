Snippr 1.1 makes the demo easier to find your way around, adds prompts as a kind of snippet, and fixes a few things 1.0 got wrong. Try it at [snippr.dev](https://snippr.dev). The demo needs no account.

## What you'll notice

- **A "Things to try" list in the demo.** It names four things a quick look would miss: dragging a snippet into a folder, AI search, having Claude write a description, and connecting an MCP client. Each line ticks itself off when you do it. Close it and the demo banner can bring it back. Members never see it. ([0049](https://github.com/RyanDanielWalker/snippr/blob/v1.1/docs/adr/0049-a-things-to-try-checklist-for-demo-guests-kept-in-a-cookie.md))
- **Prompts are a language.** Pick `prompt` for text written to be given to an AI. It shows as plain text, wraps its long lines instead of scrolling sideways, and the form and preview say "prompt" instead of "code". ([0044](https://github.com/RyanDanielWalker/snippr/blob/v1.1/docs/adr/0044-add-a-prompt-language-that-wraps-and-is-described-as-a-prompt.md))
- **Claude describes a prompt without following it.** A saved prompt is written to be obeyed, so it's sent to Claude in a way that makes it harder to take over. A reply that still looks wrong is turned down instead of filling in the description. ([0045](https://github.com/RyanDanielWalker/snippr/blob/v1.1/docs/adr/0045-put-the-saved-prompt-rules-in-the-system-prompt-and-check-the-reply.md))
- **The demo's AI has a daily budget.** All demo guests share 500 AI calls a day, and one address can use at most 100 of them. Past that, a guest sees a message saying when it's back, where they pressed the button. Members aren't affected. ([0046](https://github.com/RyanDanielWalker/snippr/blob/v1.1/docs/adr/0046-a-shared-daily-ceiling-on-demo-ai-calls.md), [0047](https://github.com/RyanDanielWalker/snippr/blob/v1.1/docs/adr/0047-give-each-address-a-share-of-the-demo-ai-ceiling.md))

## Fixed

- **Try again on the error page now works.** Before, pressing it did nothing and left you on the error page.
- **A card no longer stays dimmed after you drag it into a folder.** It used to stay faded until the page reloaded.
- **A folder's snippet count stays readable while you drag a snippet over it.** It used to nearly vanish against the highlighted row.

## Underneath

- **GitHub and Google sign-in tokens are no longer stored.** Snippr never used them, and the ones already saved were cleared. ([0039](https://github.com/RyanDanielWalker/snippr/blob/v1.1/docs/adr/0039-stop-storing-provider-tokens.md))
- **An address that uses up its share of the demo's AI is logged,** so the limit can be changed based on what real visitors do. ([0048](https://github.com/RyanDanielWalker/snippr/blob/v1.1/docs/adr/0048-log-when-an-address-uses-its-share-before-changing-it.md))
- **The MCP server reports version `1.1.0`,** and a test now keeps it equal to `package.json`.

The full list is in the [roadmap](https://github.com/RyanDanielWalker/snippr/blob/v1.1/docs/ROADMAP.md), and every decision has a record in [`docs/adr/`](https://github.com/RyanDanielWalker/snippr/tree/v1.1/docs/adr).
