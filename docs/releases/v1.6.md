Snippr 1.6 is about how it looks and how it feels to use. There are two new themes, light and synthwave, picked from a Theme menu that replaces the 8-bit toggle. The snippet form can tidy your code with one press, and its buttons stay in view on a phone. A keyboard user no longer loses their place when a button is busy or a card goes away. Try it at [snippr.dev](https://snippr.dev). The demo needs no account.

## What you'll notice

- **A light theme, and a Theme menu.** The 8-bit toggle in the header is now a Theme button. It opens a list of every theme, each with a swatch of its colors and a tick by the one in use. Light is the default turned over: a paper page, ink text, and the same tangerine accent. The menu is in the header at every screen width, so a phone can switch themes from the dashboard. Everyone still starts on the dark default. ([0078](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0078-a-light-theme-and-a-theme-menu-in-the-header.md))
- **A synthwave theme.** Hot pink buttons on deep purple, cyan for focus, a faint grid, and a glow on the wordmark. Code is colored with Synthwave '84. ([0079](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0079-a-synthwave-theme-in-sunset-pink-with-a-neon-glow.md))
- **A Format button in the snippet form.** It tidies TypeScript, JavaScript, JSON, CSS, HTML, and SQL, and then turns into Undo format in case you liked it better before. Code it can't read, like a fragment from the middle of a file, is left alone, and the form says where reading stopped. The formatters aren't part of the page: the first press for a language downloads what that language needs, once. Python, Rust, Go, and Bash aren't covered, and the button says so. ([0080](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0080-a-format-button-with-prettier-and-sql-formatter-loaded-on-first-press.md))
- **The snippet form's Save and Delete stay in view.** They sit in a bar at the bottom of the form while the code scrolls under it. On a phone, the bar sits above where toasts appear, so you never have to scroll or wait for a toast to save. ([0077](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0077-a-sticky-button-bar-on-the-snippet-form.md))
- **A signed-in member's header fits a phone.** In 8-bit it ran off the right edge, cutting off Connect and Sign out. Now it wraps onto a second row when it's full.

## For keyboard users

- **A busy button keeps focus.** Save, Delete, ✦ Generate, Format, and the rest used to let go of focus while they worked, which dropped a keyboard user back at the top of the page. ([0081](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0081-add-keeping-focus-on-generate-to-1-6.md), [0082](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0082-keep-keyboard-focus-when-a-button-is-busy-or-its-item-leaves.md))
- **When what you were on goes away, focus moves to what took its place.** Delete, archive, restore, or move a card and focus lands on the next card, like an inbox. The same goes for a revoked token, an emptied trash, and a saved or deleted folder. When nothing is left, focus goes to the list's heading. ([0082](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0082-keep-keyboard-focus-when-a-button-is-busy-or-its-item-leaves.md))

## Fixed

- **In Safari, picking a theme or a Move destination did nothing** with a mouse or a tap. The menu closed before the click arrived. Running the browser tests in WebKit, the engine behind Safari, found it. ([0083](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0083-one-helper-for-unavailable-buttons-a-lint-rule-and-a-safari-check.md))

## Underneath

- **Every theme is checked for contrast.** Text and code colors in light and synthwave meet 4.5:1, the WCAG AA ratio, and a test checks every pairing in every theme. No light theme bundled with Shiki passed, so light's code colors are a palette made for Snippr.
- **The browser tests run in WebKit and Firefox too**, with `npm run test:e2e:browsers`. CI still runs Chromium only. ([0083](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0083-one-helper-for-unavailable-buttons-a-lint-rule-and-a-safari-check.md))
- **A busy button goes through one helper, and ESLint enforces it.** A new `disabled` needs a comment saying why. ([0083](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0083-one-helper-for-unavailable-buttons-a-lint-rule-and-a-safari-check.md))
- **Prettier moved to production dependencies**, so CI's security audit covers it now that it reaches visitors' browsers. `sql-formatter` joined it. ([0080](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0080-a-format-button-with-prettier-and-sql-formatter-loaded-on-first-press.md))
- **The README shows every theme**, wide and on a phone, with the Theme menu open. The script that takes the images picks each theme through the menu. ([0076](https://github.com/RyanDanielWalker/snippr/blob/v1.6/docs/adr/0076-add-a-phone-theme-picker-and-a-readme-shot-per-theme-to-1-6.md))
- **The MCP server reports version `1.6.0`.**
